# CopybookPlusPlus
the text redactor
# Commands
## in Main
```CopybookPPTerminalSyntax
/v                       // version
/cr                      // create file
/del                     // delete file
/op                      // open file
/ex                      // exit from a program
// [text]                // comment any variants to com.: # [text], COM [text]
```
## in redact
```CopybookPPTerminalSyntax
/com.save&ex              // save & exit to main
/com.getpath              // write path. it will not saving to the file
```
> [!IMPORTANT]
> Case save
