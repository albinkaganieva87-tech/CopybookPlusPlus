# CopybookPlusPlus
the text redactor
# Commands
## in Main
```CopybookPPTerminalSyntax
/v                       //version
/cr   [filename]         //create file
/del  [filepath]         //delete file
/op   [filepath]         //open file
/ex                      //exit from a program
```
## in redact
```CopybookPPTerminalSyntax
/com.save&ex              //save & exit to main
/com.getpath              //write path. it will not saving to the file
```
